PROMPT — SISTEMA DE ORGANIZAÇÃO FINANCEIRA PERSONALIZADA
Quero criar dentro do meu aplicativo um sistema de organização financeira personalizada, baseado em um formulário de diagnóstico financeiro.
O objetivo é fazer com que o usuário responda algumas perguntas sobre sua renda, gastos, prioridades, objetivos e situação financeira. A partir dessas respostas, o sistema deverá:

Entender a realidade financeira do usuário.
Identificar suas principais prioridades.
Identificar seus gastos fixos e variáveis.
Identificar objetivos financeiros de curto, médio e longo prazo.
Distribuir a renda mensal do usuário em categorias.
Recomendar uma porcentagem da renda para cada categoria.
Converter as porcentagens em valores monetários.
Criar automaticamente "pastas", "caixinhas" ou "objetivos" financeiros.
Criar metas de economia para cada objetivo.
Gerar um checklist mensal para o usuário acompanhar.
Mostrar o progresso de cada objetivo.

10. SISTEMA DE PONTUAÇÃO
O sistema não deverá simplesmente aplicar uma regra fixa de orçamento para todos.
A distribuição deverá ser personalizada.

Cada objetivo deverá receber uma pontuação baseada em:

Importância declarada pelo usuário

Necessidade

Existência ou não de reserva
Existência ou não de dívidas
Valor necessário
Valor já guardado
Capacidade mensal de poupança
Criar um sistema de prioridade.
Exemplo conceitual:

Prioridade = importância × urgência × necessidade × situação financeira

Não é necessário utilizar exatamente essa fórmula; criar uma lógica financeira coerente e transparente.

11. DISTRIBUIÇÃO DA RENDA
Como referência inicial, utilizar:
Segurança / Futuro / Aposentadoria: 10%–25%
Gastos Fixos: idealmente até 50%–60%
Investimento Pessoal: 10%–20%
Viagens: 5%–15%
Casa Própria / Grandes Objetivos: 5%–20%
Esses percentuais NÃO devem ser obrigatórios.
O sistema deverá ajustá-los conforme o perfil do usuário.

A soma deverá sempre resultar em:

100% da renda

Caso os gastos essenciais já representem uma parcela muito alta da renda, o sistema deverá reduzir temporariamente as categorias de menor prioridade.

12. REGRA DE SEGURANÇA

Objetivos prioritários
Investimento pessoal
Viagens e desejos
A ordem poderá mudar dependendo das respostas do usuário.

20. PRINCÍPIO FUNDAMENTAL
O sistema não deve fazer o usuário sentir que está sendo "punido" por gastar dinheiro.
A proposta deve ser:

"Dar uma função para cada dinheiro que entra."

O objetivo não é simplesmente fazer a pessoa gastar menos.

O objetivo é ajudá-la a decidir:

Quanto precisa para viver
Quanto precisa proteger
Quanto pode investir
Quanto pode gastar consigo
Quanto precisa guardar para viajar
Quanto precisa guardar para comprar uma casa
Quanto precisa guardar para seus sonhos
O sistema deverá transformar uma renda mensal em um plano financeiro personalizado e acionável.
